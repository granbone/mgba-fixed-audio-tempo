# Public compatibility presentation v2

v0.3-preview candidate replaces the ownership-based catalogue with driver-family and support-status views. Only public DAT identities are listed. Unmatched developer records are retained privately.

Canonical JSON generates CSV, XLSX, COMPATIBILITY.md and README statistics. The validator reconciles all fields, status subsets and counts. Static eligibility comes from the actual production profile builder and bridge scanner, with live checks still pending. Limited passes require recorded audio comparison evidence.

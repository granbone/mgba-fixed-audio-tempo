# Corresponding source and LGPL relink inputs

The full mGBA and bridge source is the repository tree. `agbplay-source.zip` pins the separately licensed library, `relink-support.zip` supplies matching headers/static archives, and `dependency-source.zip` supplies preferred dependency sources and recipes. Original notices are retained. The distribution additionally contains `mgba-preview-source.zip` for the exact public source commit and `bridge-source.zip` for standalone relinking. See ../BUILDING.md and ../docs/RELINKING.md.
